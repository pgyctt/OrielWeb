Tauri 示例 · Commands

移植自 tauri/examples/commands：命令的五种形态。 页面代码只换了 import 前缀，命令名一个没改。

C# 命令 · 零反射 IPC
greet 同步 · 有返回值

最朴素的一条。Tauri 的 #[tauri::command] fn greet(...) 在这里是 [OrielCommand("greet")]。

async_simple_command 异步 · 无返回值

命令内部 await Task.Delay(400)，页面不会卡住；回执是 null。

simple_command_with_result Result

空字符串会走 Err 分支：页面从 error.code 拿到 foo_error。

command_arguments_struct DTO 参数

注意这一条的调用形状：Tauri 把整个 args 摊进结构体，本库按参数名取， 所以多包了一层 person。

renamed_command_new rename

Rust 的 rename 属性对应本库特性里的字符串：C# 方法名不必与命令名一致。

window_label 形态差异

原文的这条命令靠注入 Window 取 label。本库不往命令里注入宿主对象 （那会引入"参数是数据还是句柄"的第二套规则），label 在页面侧直接可读。
