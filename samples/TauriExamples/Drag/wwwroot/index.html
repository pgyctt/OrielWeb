拖动区域的可测矩阵

移植自 tauri/examples/drag。原文列了 16 条用例测 data-tauri-drag-region 的语义；这里保留能直接对照的 6 条， 并在下面把两种本库没有的取值换成等价写法。

1没有属性

按下并拖动 → 窗口不动（文本会被选中）

2data-oriel-drag-region

按下并拖动 → 窗口跟着走

3区域内的按钮

按钮不会被拖动接管

4区域内的输入框

5data-oriel-no-drag

外层可拖
这一块被显式排除，拖不动

6区域内的嵌套文本

点这里的文字也能拖（等价 Tauri 的 "deep"）

Tauri 的三种取值 → 本库的写法

Tauri 本库 说明
data-tauri-drag-region data-oriel-drag-region 裸属性。子元素里的点击也算拖动，除非命中交互元素。
="deep" 裸属性即等价 本库不做"只认直接命中"的模式，默认就是整棵子树。
="false" data-oriel-no-drag 把要排除的那块标出来，而不是把父级关掉。
按标签 / role 排除 内建排除表 button / input / select / textarea / a / contenteditable 始终不接管。不认 role——要排除请用 no-drag 属性。

宿主也可以用 WithDragRegion(selector) 指定选择器，效果与在页面上写属性一致； 两个来源取并集。
